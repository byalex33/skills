Features

Everything a paste site needs.
Nothing it doesn't.

Every feature from the original Pastify, rebuilt and extended. Now with a public API, your own branding and alerts in Discord.

Smart editor

Detects the language as you type. Format with Prettier and see lines, words and characters live.

Expiry & burn after read

Pastes expire from 10 minutes to 1 month, or vanish after the first person opens them.

Password protection

Only a scrypt hash is stored. The content never appears in the page HTML.

Linkable lines

Highlight lines like #L3-L7 and share the exact spot. Markdown preview, raw view and QR codes.

NEW

Public API

POST /documents from scripts and bots. Haste-compatible, with its own rate limit and an optional API key.

NEW

Clean-up tools

Strip terminal colours, join wrapped lines, fix PDF text, plain quotes and remove link tracking.

NEW

Your brand

Upload your logo and favicon, pick an accent colour and set SEO keywords from the admin panel.

NEW

Discord webhooks

Get a message when pastes are created, reported or deleted. Paste content is never sent.

NEW

Limits you set

Pastes per visitor, the largest paste, link length and characters. All from the admin panel.

NEW

Auto clean-up

Removes pastes nobody opened in 7 days to a year. Old pastes are safe when you turn it on.

NEW

YAML config

Set everything in one pastify.config.yml file, then fine-tune it in the admin panel.

Admin dashboard

Charts for pastes, views and languages, all-time stats, reports and paste management.

Your theme, one link

Paste a tweakcn theme link in the admin panel and the whole site restyles itself.

Command palette

Press Ctrl/Cmd+K on any page to jump, search and run actions from the keyboard.

Private by design

Pastes are unlisted, link previews never see content, and raw files are locked down.

Deploy anywhere

Vercel with MongoDB in a few clicks, or any Node host. Old Pastify databases work unchanged.

API

Paste from scripts and bots.

Send text to /documents and get a link back. Existing Haste clients work as they are, and the docs page is built in.

  • Plain text or JSON with options
  • Optional API key
  • Its own rate limit
  • Docs with examples at /docs
Terminal
Requestcurl -X POST https://paste.example.com/documents \
  -H "Content-Type: application/json" \
  -d '{"content": "console.log(1)", "expiry": "1d"}'
Answer{
  "key": "abc23xyz",
  "url": "https://paste.example.com/view/abc23xyz",
  "raw": "https://paste.example.com/raw/abc23xyz",
  "language": "javascript",
  "burnAfterRead": false
}
